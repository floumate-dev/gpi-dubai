# GPI Dubai - webinar

Stranica za prijavu na besplatan webinar uz Ornelu Šare i stranica zahvale.

- `optin.html` - stranica za prijavu, dostupna na `/optin` (forma s validacijom, odbrojavanje)
- `index.html` - preusmjerava na `/optin`
- `hvala.html` - stranica zahvale (dodavanje u kalendar)

Datum webinara mijenja se u objektu `WEBINAR` na dnu obje datoteke.
